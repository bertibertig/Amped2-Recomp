First public build of **Amped2-Recomp**: a native PC port of **Amped 2 (original Xbox, 2003)**, made by
statically recompiling the game's Xbox code to C with [xboxrecomp](https://github.com/sp00nznet/xboxrecomp).
No emulator.

This is an **early, experimental** release for **Linux**: the game boots, the menus run at 60 fps and you can
ride the first mountain (Millicent 1) at about 55 fps, but a lot is still untested.

> ⚠️ **No game files included.** You need your own, legally obtained copy of Amped 2 for the Xbox, **PAL/EU
> version** (title ID 4D530041). Other versions are not tested. Never share game files.

## Getting started

1. Download `Amped2-Recomp-v0.1.0-linux-x86_64.tar.gz` below and unpack it
   (`tar xzf Amped2-Recomp-v0.1.0-linux-x86_64.tar.gz`).
2. Prepare the game files (next section) in the package's `game_files/` folder.
3. Start the game with `./run.sh` from the package folder.

**Linux** needs glibc 2.39+ (Ubuntu 24.04+, Fedora 40+, Arch, SteamOS 3.6+), SDL2 and a Vulkan driver
(`sudo apt install libsdl2-2.0-0 libvulkan1 mesa-vulkan-drivers`).

There is no Windows or macOS package yet (see Platform status).

## Preparing the game files

The game data always comes from **your own Amped 2 disc**; nothing of it is in this repository or in a release.
Supported is the **PAL/EU version** (title ID 4D530041, `default.xbe` SHA-1
`38e63cd016bf084d999e0a911933a52191bfc378`); other versions are not tested.

1. **Make a disc image** (`.iso`) of your Amped 2 Xbox disc, e.g. on a modded Xbox or with an Xbox-compatible DVD
   drive. Both a full disc image (Redump style) and a game-partition XISO work.
2. **Extract the image** with [extract-xiso](https://github.com/XboxDev/extract-xiso) (AUR `extract-xiso-git`) or
   [xdvdfs](https://github.com/antangelo/xdvdfs) (`cargo install xdvdfs-cli`):

   ```bash
   extract-xiso -x "Amped 2.iso" -d game_files
   ```

   or `xdvdfs unpack "Amped 2.iso" game_files`. Already have an extracted disc folder? Copy its contents instead.
3. **Put it in the right place**: a folder named `game_files`
   next to `run.sh` and `amped2_recomp` in the unpacked package folder (the package already has an empty one with
   a short README in it).
4. **Check the layout**: `default.xbe` must sit directly in `game_files/`, not in a subfolder (no
   `game_files/Amped 2/default.xbe`). The whole disc is about 4 GB; keep every file and folder as extracted (the
   letter case of the names does not matter).

```text
Amped2-Recomp-v0.1.0-linux-x86_64/
├── amped2_recomp
├── run.sh
└── game_files/
    ├── default.xbe
    ├── Audio/
    ├── Levels/
    ├── Movies/
    └── … (the rest of the disc)
```

Without `game_files/default.xbe`, `./run.sh` stops with a message telling you where the files belong. Saves and
the game's cache go to `~/.local/share/xboxrecomp`, not into `game_files/`.

## What works

- Boot with the Microsoft Game Studios logo (skipped by default) and the intro movie, played in real time
- Audio through the emulated Xbox APU
- Legal screen, title, profile creation and Choose a Look, main menu, career menu and level select
- The 3D rider in the menus and on the slope, complete and matching the original
- **Riding**: Millicent 1 (Evergreen) loads and plays, with the HUD, the challenge cards and the goals board
- Keyboard as player 1, XInput/SDL controllers with hotplug and rumble

## Features

- **Vulkan renderer**: 60 fps in the menus, about 55 fps on the slope; the Xbox vertex programs run on the GPU.
  The software renderer (`AMPED2_RENDERER=cpu`) is kept as a slow reference.
- **Controllers**: Xbox 360/One/Series, 8BitDo (X-input), anything SDL2 knows; plug in at any time; the game's
  vibration goes to the pad's motors
- **Keyboard** with Amped 2 keys: WASD to steer, Space to accelerate/jump, U/O for lip tricks and jibs, IJKL for
  grabs, Escape to pause, Tab to reset (works the same on QWERTZ/AZERTY)
- Skippable logo and intro (`AMPED2_SKIP_LOGOS`, `AMPED2_SKIP_INTRO`)

## Platform status

- **Linux (x86-64)**: tested on Garuda Linux (Arch) with an NVIDIA GPU (proprietary driver): boot, menus and a
  ride on Millicent 1. Other GPUs and drivers (AMD, Intel, Mesa) are not tested yet.
- **Steam Deck**: not tested yet.
- **Windows**: no package yet. The MinGW cross build compiles but has not been tested; a Windows release will
  follow once it is.
- **macOS**: not started.

## Known issues

- **Music can stop suddenly** while playing; it comes back later, but very quiet and with crackling.
- Only the menus and the first rides of the career (Millicent 1) have been checked; a full career, saving and
  loading over several sessions and multiplayer are **not verified** yet.
- Rides run at about 55 fps instead of a steady 60.
- The rider has no shadow yet.
- Internal resolution fixed at 640x480 (4:3), window only: no resolution scaling, widescreen or full-screen modes
  yet – planned.
- Audio is mixed to stereo (no 5.1 yet).
- The save folder `~/.local/share/xboxrecomp` (its `Cache` part) is shared with SSX3-Recomp.

Please report bugs at [Issues](https://github.com/bertibertig/Amped2-Recomp/issues) with the console output
(`./run.sh 2>&1 | tee run.log`).

## Building it yourself

Linux, or in the Ubuntu 24.04 container (`scripts/docker.sh`).
